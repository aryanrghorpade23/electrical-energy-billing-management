# Electrical Energy Consumption and Billing Management System

A menu-driven C mini-project for maintaining electricity consumer records, calculating monthly energy consumption and bills, detecting unusually high consumption, and retrieving previous bills.

## Features

- Register a consumer using a unique consumer ID and name.
- Update a consumer's name and find a consumer by ID.
- Calculate consumed units from previous and current meter readings.
- Calculate an electricity bill using progressive tariff slabs.
- Flag high usage when current consumption exceeds 150% of previous consumption.
- Save and load consumer records and billing history.
- Retrieve a past bill using consumer ID, billing month, and billing year.

## Tariff used in this project

The following values are illustrative project assumptions, not an official electricity tariff:

| Consumption slab | Rate |
|---|---:|
| First 100 units | ₹3 per unit |
| Next 100 units | ₹5 per unit |
| Above 200 units | ₹7 per unit |

A fixed charge of ₹100 is added, followed by a 5% tax on the energy charge plus fixed charge.

**Example:** For 230 units, the energy charge is ₹1,010, fixed charge is ₹100, tax is ₹55.50, and the total bill is ₹1,165.50.

## Build and run

Requirements: GCC, G++, GNU Make, and (for unit tests) Google Test.

```bash
make
make run
```

## Run unit tests

```bash
make test
```

The test target requires Google Test headers and libraries to be installed on your system.

## Clean build files

```bash
make clean
```

## Data storage

The application stores consumer records in `data/consumers.txt` and billing history in `data/billing_history.txt`. These runtime files are ignored by Git so personal/test records are not committed.

## Notes

- `include/types.h` contains the shared structures, limits, and status codes used by the project.
- The main application is written in C. Google Test cases are written in C++ and test the C modules.
- This is an academic demonstration project. Verify the tariff assumptions before using any billing calculation for real-world billing.
